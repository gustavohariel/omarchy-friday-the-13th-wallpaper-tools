# omarchy-friday-the-13th-wallpaper-tools

Script that builds the wallpapers of the [Friday the 13th Omarchy theme](https://github.com/gustavohariel/omarchy-friday-the-13th-theme):
free-licence fog photos from Wikimedia Commons, graded into Crystal Lake at night (gradient map, vignette, film grain).

Needs `curl` and ImageMagick (`magick`).

```bash
./make-wallpapers.sh   # downloads originals to cache/, writes backgrounds/
```

Source photos and their licences are credited in the theme's README.
